# Security reports

Keep API keys, Firebase credentials, voice profiles, screenshots and memory out of
issues and pull requests. Use GitHub's private vulnerability reporting feature if
enabled; otherwise contact the repository maintainer privately before disclosing
exploit details. Do not post credentials to demonstrate a vulnerability.

See [JoJo privacy](JOJO_PRIVACY.md) for data flow, voice-matching limits and secret
rotation/history-cleanup requirements. This experimental project has no security
audit certification or guaranteed response time.
